# Post 2 — Anchor tags in PDFs

---

If you build documents with code or mail-merge, drag-and-drop fields don't scale.

So we added anchor tags to Docracy.

Drop tags like {{sig1}}, {{date_2}}, or {{dropdown_1:Yes|No|Maybe}} into your PDF.

Upload it → Docracy finds them, places the right field type, and whiteouts the tag text.

Same prepare screen as auto-detect. Works great for templates you send over and over.
